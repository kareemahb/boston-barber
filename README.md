# 💈 Boston Street Barbers | Small Business Website
 
A one-page website for **Warren Street Barbers**, a neighborhood barbershop in Boston. The site gives customers the basics before they walk in: services and prices, the shop's story, location, phone number, and hours.
 
Built with plain HTML and CSS as part of my small business website series.
 
🔗 **Live Site:** [bostonbarbersmb.netlify.app](https://bostonbarbersmb.netlify.app/)

## ✨ What's on the Page
 
| Section | What it shows |
| --- | --- |
| **Header** | Shop name and navigation |
| **Hero** | "Fresh Cuts. No Waiting." with a **Book a Chair** button |
| **Cuts & Prices** | Five services, from a $18 kids cut to a $40 cut and beard lineup |
| **About the Shop** | The shop's story since 2012, with a photo of the shop |
| **Footer** | Address, phone number, and hours (closed Mondays) |
 
---
 
## 🎨 Design
 
- **CSS Grid layout** that places the price list, About text, and photo in a two-column layout
- **Local voice** in the copy (the Celtics all winter and the Sox all summer) to make the shop feel like part of the neighborhood
- **Simple, scannable price list**, so customers can find a price at a glance
---
 
## 🛠️ Tech Stack
 
- HTML5
- CSS3 (CSS Grid)
- Hosted on **Netlify**
No JavaScript, frameworks, or build tools.
